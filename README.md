# KRKREE Personal Nexus

一个适合 GitHub Pages 托管的静态个人导航页，包含主题切换、互动终端、动态背景、复制反馈和响应式导航卡片。

## 修改个人信息

打开 `script.js`，修改 `profileLinks` 数组里的 `value`：

- `QQ`: 你的 QQ 号
- `微信`: 你的微信号
- `Bilibili`: 你的 B 站主页链接
- `Bangumi`: 你的 Bangumi 用户主页链接

二维码图片放在 `assets/qq-qr.jpg` 和 `assets/wechat-qr.jpg`。

## 发布到 GitHub Pages

把这些文件推送到仓库后，在 GitHub 仓库设置里开启 Pages，发布源选择当前分支即可。
